Ako projekt vznikol

Už v prvom ročníku strednej školy za mnou prišla moja škola s ponukou na vytvorenie webu na registráciu žiakov na krúžky.

Mal som vtedy len 16 rokov a minimálne skúsenosti s backendom, takže som túto príležitosť nechcel pustiť.

Web som dokončil za 2 mesiace. Programoval som sám, bez cudzej pomoci. Pri dizajne som sa občas poradil s učiteľmi.

O projekte

Web slúži na predbežnú registráciu žiakov základných aj stredných škôl na krúžky, ktoré škola ponúka. Škola vďaka nemu vidí, o ktoré krúžky je záujem.

Funkcie

Pre žiakov

  • Po registrácii používateľovi pošleme email na potvrdenie registrácie

Pre administrátora

  • Hlavná stránka sa skladá z krúžkov a úspechov priamo z databázy, takže škola ich môže meniť bez zásahu do kódu
  • Štatistíky krúžkov, ako existujúcich, tak aj vymazaných
  • Vytváranie, úprava a mazanie krúžkov a úspechov
  • Tabuľka registrácií s filtrovaním, mazaním a exportom do xlsx
  • Emaily pre žiakov konkrétneho krúžku

Na pozadí

  • Každý pondelok o 2:00 sa automaticky zálohujú registrácie

Tech stack

Frontend

  • Vanilla HTML/CSS/JS

Backend

  • Server: Node.js + Express
  • Databáza: MySQL (mysql2)
  • Autentifikácia: JWT pre admin panel, heslo hashované cez bcrypt
  • Zabezpečenie: rate limiting (express-rate-limit) na registrácii a prihlásení, ochrana proti SQL injection
  • Emaily: Nodemailer (SMTP) + OAuth2 cez Microsoft Entra ID (MSAL), Microsoft 365
  • Konfigurácia: dotenv

Čo mi projekt dal

Bol to môj prvý projekt, ktorý nebol len pre mňa. Musel som myslieť na veci, ktoré hobby projekt nerieši: zálohy dát, ochranu prihlásenia pred hádaním hesiel a admin rozhranie, ktoré zvládne človek bez programátorských znalostí.
